predicted, and correct each report's novelty wording. Each changed report carries a dated
"Post-review correction (2026-10-31)" note at the top.

look-up script and extracted xlsx were held in `results/revision/scratch_novelty/`, deleted afterwards):

## Notes on `a2_novelty_overlap.tsv`

These are observations; the TSV was not changed.

- **C5orf34:** `wainberg_module_d_ge0p5_with_top10 = False` is correct but misleading. The d = 0.2 module 58 contains all 10 top-10 partners, and SD3 gives the same function.
- **TM2D1/TM2D2:** `kim2019_edge_top10 = False` is right. Kim 2019 lists only TM2D-paralogue edges, and paralogues are excluded from the top-10 lists.
- **PLEKHH3:** `wainberg_in_any_module = True` refers only to the 598-gene d = 0.2 catch-all module 18, so it is not a prior prediction.
- **RBM34:** `wainberg_modules` lists module 706 (ufmylation) among its top three. Modules 323 and 986 (pre-60S) carry the more relevant labels.
