# Gene knownness feature table (pre-registration input)

Generated by `scripts/02_gene_knownness_table.py` (PMID cut-offs by `scripts/02a_pmid_date_cutoffs.py`). Feature table only: **no selection thresholds are applied here**; the thresholds in the overlap section are descriptive, chosen by the PI's request, not criteria. No DepMap values were read (header only) and no co-essentiality was computed.

Output: `results/preregistration/gene_knownness_features.tsv` -- 19,296 rows (HGNC Approved, locus_group 'protein-coding gene'), 68 columns.

## Columns

| column(s) | definition |
|---|---|
| hgnc_id, symbol, entrez_id, ensembl_gene_id, uniprot_ids, name, locus_type, location, gene_group | Verbatim from HGNC `hgnc_complete_set.txt` (status Approved, locus_group 'protein-coding gene'). `location` = cytoband; `uniprot_ids` and `gene_group` are '|'-separated as in HGNC. |
| in_depmap | Entrez ID of the gene equals the Entrez ID parsed from a DepMap 26Q3 `CRISPRGeneEffect.csv` column name `SYMBOL (ENTREZ)` (header line only; matching on Entrez as the co-essentiality tool does). NB the tool additionally drops genes without HGNC UniProt IDs and flags low-coverage (high-NaN) genes; NaN coverage was NOT computed here because that requires reading values. |
| symbol_pattern | Descriptive only. Name of the first matching placeholder pattern (orf = C<n>orf<n>/CXorf/CYorf, FAM, KIAA, TMEM, CCDC, SMIM, PRR, LOC, FLJ) or 'domain:<prefix>' for domain-descriptive family names (ANKRD, LRRC, WDR, TTC, ARMC, HEATR, ZNF, ZSWIM, ZCCHC, ZC3H, KLHL, SPATA, C2CD, DCAF, TBC1D, ABHD, NUDT, METTL); empty if none. |
| symbol_placeholder | True iff symbol_pattern is one of the strict placeholder patterns (not 'domain:*'). |
| n_exp_BP | Distinct GO BP terms (current GAF) with experimental evidence (EXP, IDA, IPI, IMP, IGI, IEP, HTP, HDA, HMP, HGI, HEP), excluding NOT and the uninformative terms (only the BP root/grouping terms matter here). |
| n_exp_MF_informative | Distinct informative GO MF terms with experimental evidence. |
| n_exp_CC | Distinct GO CC terms with experimental evidence (CC root excluded). |
| n_exp_informative_BPMF | Distinct informative BP+MF terms with experimental evidence (current GAF). The main GO knownness feature. |
| n_exp_informative_BPMF_lowthroughput | As n_exp_informative_BPMF but HTP codes (HTP, HDA, HMP, HGI, HEP) excluded -- i.e. only EXP, IDA, IPI, IMP, IGI, IEP. Added because proteome-wide screens (e.g. RNA-interactome capture -> 'RNA binding' HDA; 'cadherin binding' HDA) give many otherwise unstudied proteins one term. |
| n_exp_BPMF_all_terms | Distinct BP+MF terms with experimental evidence INCLUDING the uninformative terms (e.g. protein binding); for comparison. |
| n_ibas_BPMF | Distinct informative BP+MF terms with phylogenetic evidence (IBA, IBD, IKR, IRD). |
| n_comp_BPMF | Distinct informative BP+MF terms with computational/author/curator evidence (ISS, ISO, ISA, ISM, IGC, RCA, TAS, NAS, IC). |
| n_any_BPMF_nonIEA | Distinct informative BP+MF terms with any evidence except IEA and ND. |
| n_IEA | Distinct informative GO terms (any aspect) with IEA evidence. |
| has_ND_BP / has_ND_MF | Gene has an ND (no biological data) annotation to the BP / MF root. |
| nrows_<P|F|C>_<exp|phylo|comp|iea|nd> | Raw number of (non-NOT) GAF annotation rows per aspect x evidence class (not de-duplicated, uninformative terms included). |
| has_any_go_annotation | Gene has >= 1 non-NOT row in the current GAF. |
| n_exp_informative_BPMF_<YYYY_MM> | n_exp_informative_BPMF computed identically on the archived GO release (2018_07 = release 2018-07-02, 2019_07 = 2019-07-01, 2020_06 = 2020-06-01, 2022_07 = 2022-07-01), mapping rows by UniProt accession only (no symbol fallback), GO alt_ids normalised with that release's go-basic.obo. |
| has_any_go_annotation_<YYYY_MM> | Gene has >= 1 non-NOT row in that archived GAF. |
| n_pubmed | Distinct PMIDs linked to the gene's Entrez ID in NCBI gene2pubmed (human). |
| n_pubmed_focused | As n_pubmed, counting only PMIDs linked to <= 10 distinct human GeneIDs in gene2pubmed (any gene type; counts per PMID from the full current file). |
| n_pubmed_focused3 | Same with <= 3 genes per PMID. |
| n_pubmed_focused_before_<YYYY_MM> | n_pubmed_focused restricted to PMIDs < the cut-off PMID for that date (date proxy; see 'PMID cut-offs'). Genes-per-PMID is still computed on the current file. |
| uniprot_entries, n_uniprot_entries | Swiss-Prot (reviewed) entries assigned to the gene. |
| annotation_score | Max UniProt annotation score (1-5) over the gene's reviewed entries; NA if none. |
| protein_existence, protein_existence_level | Best (lowest-level) protein existence over entries: 1 protein level, 2 transcript level, 3 inferred from homology, 4 predicted, 5 uncertain. |
| has_function_cc | Any reviewed entry has a non-empty Function [CC] comment. |
| function_cc_length | Max length (characters) of the Function [CC] text after removing 'FUNCTION:', {ECO:...} evidence tags and '(PubMed:...)' citations. |
| n_uniprot_pubmed | Distinct PMIDs cited in the gene's reviewed entries (union). |
| unknome_knownness | Max Unknome protein-level 'knownness' over the gene's human Unknome rows (protein table column `knownness`, release 18 Mar 2026). Per Rocha et al. 2023 (PLoS Biol 21:e3002222) knownness is an evidence-weighted sum over the protein's GO annotations (experimental evidence weighted most); 0 = nothing known. NA = no human Unknome row mapped. |
| unknome_cluster_knownness | Knownness of the gene's Unknome orthology cluster (cluster table). Verified here to equal the MAX protein knownness over all proteins of all species in the cluster (100% of 15,589 clusters), i.e. 'is anything known about any orthologue'. Max over the gene's clusters. |
| unknome_cluster_id, n_unknome_proteins | Unknome cluster id(s) and number of human Unknome proteins mapped. |
| tdl | IDG Target Development Level (Tclin > Tchem > Tbio > Tdark) from Pharos/TCRD v6.13 (PharosTCRD_UniProt_Mapping.tsv, 2023); highest level if several accessions; empty if unmapped. |

## Uninformative GO terms (excluded from all 'informative' counts)

Matched after normalising GO alt_ids to primary ids with the same release's go-basic.obo. The list was built from the PI's terms plus generic interaction terms (partner unspecified) and high-level grouping terms one or two levels below the roots. ## Evidence classes

- experimental: EXP, HDA, HEP, HGI, HMP, HTP, IDA, IEP, IGI, IMP, IPI (high-throughput subset: HDA, HEP, HGI, HMP, HTP)
- phylogenetic: IBA, IBD, IKR, IRD
- computational/author/curator: IC, IGC, ISA, ISM, ISO, ISS, NAS, RCA, TAS
- IEA separately; ND separately. Rows whose qualifier contains the token NOT are removed before anything else (GAF 2.1 'NOT', 'NOT|contributes_to'; GAF 2.2 'NOT|enables' etc.).

## PMID cut-offs (date proxy -- an approximation)

PMIDs are assigned roughly sequentially when a record enters PubMed. For each date D, `scripts/02a_pmid_date_cutoffs.py` queried NCBI E-utilities esearch for all PMIDs with Entrez date `"YYYY/MM/DD"[EDAT]` on each of D-3 .. D+2 and set cutoff_pmid(D) = 1st percentile of PMIDs with EDAT in [D, D+2] (robust to back-filled records that carry an old EDAT with a new PMID). 'Before D' = PMID < cut-off. This approximates the PubMed *entry* date, not the publication date (epub-ahead-of-print and back-filled records are misdated); boundary misclassification is ~1% in each direction within the +-3-day windows (columns below), negligible at the gene-count level. The cut-off TSV is in `results/preregistration/pmid_date_cutoffs.tsv` (per-day quantiles in `pmid_date_cutoffs_days.tsv`).

## Known data caveats

- TCRD TDLs are from the 2023 TCRD v6.13 mapping file (live Pharos may differ); genes characterised since 2023 can still be 'Tdark'.
- The current GOA GAF (2026-05-21) is older than the ontology (2026-07-26); alt_ids are normalised with the current ontology, obsolete terms are kept as-is (counted).
- The 2018-07-02 archive GAF lists 'NCBITaxon:' in some taxon fields (IBA rows); taxon is not used for filtering, so this has no effect.
- gene2pubmed genes-per-PMID counts include all human GeneIDs (incl. non-coding/pseudo); focused counts are therefore slightly conservative for papers touching many loci.
- PMID cut-offs approximate PubMed entry date (see above).
- 64 DepMap 26Q3 gene columns are HGNC loci with locus_group 'other' (clustered protocadherins PCDHA/B/G, readthrough genes, UGT1A complex-locus constituents); they fall outside the protein-coding universe used here.
- 20 HGNC protein-coding genes have an empty `uniprot_ids` field (e.g. UBE2O, ABHD4); 5 of them are rescued for GO/Unknome/TCRD via the Swiss-Prot entry's HGNC cross-reference. The co-essentiality tool drops DepMap genes without HGNC UniProt IDs, so these genes cannot be scored by it even if in_depmap is True.
- Several well-studied genes are absent from the DepMap 26Q3 CRISPRGeneEffect header (e.g. POLR2A, GSTT1, HSPA1A, SMN1/2, HBA1/2, all 13 mitochondrially-encoded genes): in_depmap = False for 926 protein-coding genes.
- Unknome / TCRD / archived GO are mapped via current HGNC/UniProt accessions; accessions merged or deleted since are unmapped (rates above).
