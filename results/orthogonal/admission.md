# Orthogonal source admission (DESIGN.md v2.3 §5.2)

Generated by `scripts/20_source_admission.py` (M4, before any U prediction; annotation and orthogonal data only -- no DepMap gene effects, no co-essentiality output, no hit@1 outcome). Loaders: `src/orthogonal.py`; ID mapping QC: `mapping_qc.md`; per-source gene coverage: `coverage.tsv`; machine-readable: `admission.tsv`.

## Rules applied

- Pair sources: co-complex odds ratio vs degree-matched random pairs (10 per co-complex pair, same degree bins, not co-complex), continuous sources dichotomised at the 95th row percentile (mean of the two row percentiles >= 0.95); 95% percentile CI over 1000 bootstrap resamples of complexes (seed 0); **admitted iff lower CI > 2**. Burke 2023: co-complex and random pairs restricted to modelled (HuRI u hu.MAP) pairs.
- Gold standard (primary): 2538 non-hu.MAP complexes (Complex Portal 2020 after excluding 111 entries cross-referenced to hu.MAP as 'identity'; GO CC 518 complex terms under GO:0032991 with D1 evidence, direct membership), 2-300 members, 4547 genes. Sensitivity: GO CC membership propagated over is_a/part_of (2611 complexes; columns `*_propagated`).
- Localisation sources: agreement (shared compartment, `config/localisation_map.tsv`) with current GO CC (D1 evidence; annotations from the sources themselves excluded) on H genes; Wilson 95% CI; **admitted iff >= 200 H genes and lower CI > 0.6**. Non-H agreement is descriptive only.
- §5.1b: STRING experiments, BioGRID LTP, BioPlex and OpenCell form one P source group (union of the admitted components: BioPlex3, OpenCell_PPI, BioGRID_LTP, STRING_exp); Human Cell Map SAINT is a separate P source.

## Notes

- Admission uses only annotation agreement / co-complex enrichment; no U-gene prediction and no hold-out outcome was read.
- CCLE proteomics is flagged (lines shared with DepMap, §5.1).
- Consequence for §5.3/§5.4 (PI attention): OpenCell, Human Cell Map NMF and MitoCarta agree well with GO CC but fail only the >= 200-H-gene rule, so HPA is the only admitted L source. The contradiction rule needs >= 2 high-reliability sources; with admitted sources only it can never fire. `src/support.py` accepts `contradiction_sources` so the four named high-reliability sources can be used for the contradiction gate regardless of admission -- whether to do so is a PI decision (DEVIATIONS.md if adopted).
- Bootstrap replicates for §5.2 are not fixed in DESIGN/frozen.yaml; 1,000 used (seed 0). Gold-standard size window 2-300 and direct GO CC membership are implementation choices of this script (propagated membership reported as sensitivity).
